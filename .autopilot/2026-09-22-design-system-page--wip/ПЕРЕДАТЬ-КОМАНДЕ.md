## Контекст: что вообще построено

Полное описание — `.autopilot/2026-09-22-design-system-page--wip/`:

- `spec.md` — спецификация
- `manifest.md` — требования заказчика с дословными цитатами и статусами
- `interfaces.md` — **главный файл**: что каждый модуль выставляет наружу, чем наполнена
  структура, какие известны слабые места
- `tickets/` — пять тасков с критериями приёмки

Коротко: из любого `.pptx` система вытаскивает дизайн-систему шаблона (роли цветов
по доле площади, сочетания, контрасты WCAG, лестницу типографики из восьми уровней,
сетку) и достраивает то, чего в шаблоне нет (плашки, бейджи, три стиля списков,
разделители, callout) из его же примитивов — цвета слотом темы, кегля из типошкалы,
отступа долей шага сетки. Результат — одна самодостаточная HTML-страница по семи
разделам, открывается двойным кликом без интернета.
