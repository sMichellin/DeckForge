# Спецификация: план Б · поток B (#244)

## Задача

Колода собирается копией слайда-примера шаблона. Писатель потом «угадывает», что
лишнее: по координатам с допуском 1 %, каскадом по линиям, по повторам каталога.
Каталог принимал за повтор ряд, а не карточку, поэтому 28.09 на VK Tech шесть слайдов
из десяти вышли с пустыми карточками: в `ex018` текст лёг в карточки 1 и 4 ряда,
а 2, 3 и широкая карточка остались пустыми рамками. Дизайн-система до рецептных
слайдов не доходит вовсе: нет перестроения ряда, контраста текста на плашке и подъёма
кегля до порога читаемости (подписи `ex018` — 9 pt при пороге 10 pt, строка 7 — 10 блоков).
Слайд, которому пример не подходит, втискивается в «ближайший по местам» и теряет блоки.

## Решение

Три change, по одному PR в `plan-b`, каждый — по циклу OpenSpec:

1. **4 `the-writer-removes-whole-groups`** — при паспорте писатель удаляет не угадыванием,
   а группами паспорта: незаполненная карточка уходит целиком, в ряду остаются первые.
2. **5а `the-design-system-lays-out-recipe-slides`** — при паспорте дизайн-система
   подгоняет рецептный слайд: оставшиеся карточки ряда на всю ширину по сетке шаблона,
   цвет текста на плашке из пар контраста, кегль не ниже порога читаемости.
3. **5б `no-example-goes-by-design`** — слайд без примера (`recipe_id is None`)
   верстается дизайн-системой на макете нативными объектами, без снятых и сплющенных блоков.

Везде: новое поведение включается только при `recipe.passport is not None`; без паспорта
(путь `legacy`) файл выходит прежним байт в байт.

## Решения по реализации

1. **Удаление группами — внутри `rendering/recipe_slide.py`, одной развилкой в `clone_recipe`.**
   С паспортом — новый путь (перенос в ряду → запись зон → удаление незаполненных групп
   и пустых мест → `_drop_unfilled_frames`); без паспорта — прежняя последовательность
   без единого изменения. Почему: оба пути живут до приёмки, и расхождение должно быть
   видно в одной функции, а не размазано по флагам.
2. **Перенос в ряду делается до записи** — как отображение «зона блока → зона цели».
   Блок IR при этом не меняется: IR принадлежит композиции, писатель только решает, куда
   положить текст. Кегль вписывания берётся тот же (`fit_report` блока): группы ряда
   одного размера (допуск паспорта 10 %).
3. **Геометрия перестроения (5а) пишется только в `a:off`/`a:ext` копии** — фигуры шаблона
   и макеты не трогаются. Для фигур внутри `p:grpSp` координаты пересчитываются в систему
   группы (`chOff`/`chExt`), как их уже читает `_placed`.
4. **Порог читаемости и контраст — ответы `DesignRules`**, а не числа в писателе
   (правило 2): `reading_floor_pt`, `block_gap_emu()`, `accent_ink`, `number_ink`, пары контраста ДС.
5. **Эталон «байт в байт» снимается первым шагом change 4, до правки кода** — XML слайда
   синтетического примера и одного примера настоящего шаблона (если шаблон есть локально),
   записанный текущим кодом. Сравнение — по XML частей слайда (zip-метки времени не сравниваются).
6. **Мерило — скрипт в scratchpad, не в репозитории** (`scripts/**` — тимлида): пересборка
   фикстур 28.09 писателем, рендер PNG через LibreOffice (`soffice.com`), подсчёт по группам
   паспорта и глазами по листу PNG. Числа и способ — в proposal.
