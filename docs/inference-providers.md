# Где брать инференс

Обзор проверен вызовами, а не по документации. Дата проверки — 15.09.2026.

## Ограничение, из-за которого половина вариантов отпадает

ТЗ требует модели **с открытыми весами** под **Apache-2.0 или MIT**, LLM/VLM **≤ 35B**.
Это дисквалифицирующее требование: не «желательно», а условие засчитывания решения.
Поэтому провайдер оценивается не по цене и удобству, а сначала по тому, отдаёт ли он
модели, которые вообще можно использовать.

## Итог

| Провайдер | Бесплатно | Пригодные модели | Вердикт |
|---|---|---|---|
| **OVHcloud AI Endpoints** | Qwen3.8-27B по цене 0/0 | 7 пригодных из 25, включая открытую Mistral Small 3.2 24B | **лучший каталог**, нужен токен AI Endpoints |
| **Groq** | да, 8000 токенов/мин | Qwen3.8-27B (текст + картинки), GPT-OSS-20B | **лучший для отладки: 0.3–0.4 с на вызов** |
| **Cloudflare Workers AI** | да, 10 000 нейронов/сут | Qwen3.8-27B, Qwen3-30B-A3B, **Mistral Small 3.1 24B** | рабочий, судья отвечает за 2–3 с |
| **Локальный Ollama** | да, без лимитов | `qwen3:8b`, `qwen3-vl:8b` | когда облачные лимиты мешают |
| Роутер HuggingFace | лимит кредитов аккаунта | Qwen3.8-27B, Qwen3-VL-30B-A3B | рабочий, кредиты кончаются быстро |
| OpenRouter | нет | Qwen3-VL-8B, Qwen3.8-27B, Qwen3.5-9B | от $0.10 за 1M токенов |
| vLLM на своей GPU | железом | любые | целевой путь для финала |
| Mistral API | лимит, 429 сразу | **нет** | ❌ не годится |
| MuleRouter | ключ рабочий | **нет** | ❌ не годится |
| srouter.ru | 1 пригодная из 4 | `qwen/qwen3.8-27b-free` | ⏳ нет квоты на аккаунте |
| YandexGPT, x.ai Grok | — | **нет** | ❌ дисквалифицируют |

## Подробности проверки

### OVHcloud AI Endpoints: лучший каталог из проверенных

Эндпоинт `https://oai.endpoints.kepler.ai.cloud.ovh.net/v1`, OpenAI-совместимый,
каталог моделей публичен и отдаётся без авторизации.

Из 25 позиций **семь проходят по ТЗ** — больше, чем у любого другого провайдера:

| Модель | Веса | Лицензия | Размер | Цена $/1M |
|---|---|---|---|---|
| **Qwen3.8-27B** | `Qwen/Qwen3.8-27B` | apache-2.0 | 27.8B | **0 / 0** |
| Mistral-Small-3.2-24B-Instruct-2506 | `mistralai/…-2506` | apache-2.0 | 24.0B | 0.10 / 0.31 |
| Qwen3-32B | `Qwen/Qwen3-32B` | apache-2.0 | 32.8B | 0.09 / 0.25 |
| Qwen3.6-27B | `Qwen/Qwen3.6-27B` | apache-2.0 | 27.8B | 0.47 / 3.19 |
| Qwen3.5-9B | `Qwen/Qwen3.5-9B` | apache-2.0 | 9.7B | 0.12 / 0.18 |
| Mistral-Nemo-Instruct-2407 | `mistralai/…-2407` | apache-2.0 | 12.2B | 0.14 / 0.14 |
| Mistral-7B-Instruct-v0.3 | `mistralai/…-v0.3` | apache-2.0 | 7.2B | 0.11 / 0.11 |

Два обстоятельства делают его самым интересным:

* **`Qwen3.8-27B` отдаётся по цене 0/0** — единственная бесплатная облачная позиция,
  проходящая по ТЗ, из всех проверенных провайдеров;
* здесь есть **открытая `Mistral-Small-3.2-24B-Instruct-2506`**, которую сам Mistral
  через свой API уже не раздаёт (см. ниже).

Не проходят: `Qwen2.5-VL-72B-Instruct` (лицензия `other`), `Meta-Llama-3_3-70B` (Llama
Community), `Qwen3.5-397B-A17B` (403B при потолке 35B).

**Токен нужен отдельный, и это не любой токен аккаунта.** Проверены два варианта,
оба не подошли:

* ключи приложения OVH API (application key / secret / consumer key) — эндпоинт отвечает
  403 и на них, и на анонимный запрос; сами ключи валидны только в регионе CA и с пустой
  областью действия (`/cloud/project` → «This call has not been granted»);
* персональный токен доступа (PAT, `kind: pat`) — подпись сходится, но ответ
  `401 Your token is not allowed to perform the required actions on any tenant`.
  Диагностический признак: **без** токена публичный `/v1/models` отвечает 200,
  **с** ним — 401. То есть токен активно отвергается, а не игнорируется: у него нет
  привязки к проекту Public Cloud с правами на AI Endpoints.

Рабочий ключ берётся в самом сервисе: Public Cloud → проект → AI Endpoints → API keys.

### srouter.ru: каталог читается, генерация упирается в квоту аккаунта

Базовый URL — `https://srouter.ru/v1` (не `/api/v1` и не `api.srouter.ru`). Под капотом
One API: ошибки приходят с `"type": "one_api_error"`.

Первый присланный ключ (`01a0a9…c4fe`) отвергался во всех четырёх схемах авторизации
с ответом `token not found for key` — токена с таким значением на стороне сервиса нет.

Второй ключ (`sk-g1sk…`) **аутентифицируется**: каталог моделей открывается, а
`/v1/dashboard/billing/subscription` сообщает неограниченный лимит и нулевой расход.
Но любая генерация отвечает `403 user quota is not enough` — и на моделях с пометкой
`-free` тоже. Ограничение не на токене, а на аккаунте за ним.

Каталог небольшой — 4 позиции, из них по ТЗ проходит **одна**:

| Модель | Веса | Вердикт |
|---|---|---|
| `qwen/qwen3.8-27b-free` | `Qwen/Qwen3.8-27B`, apache-2.0, 27.8B | ✅ годится |
| `qwen3.6-flash` | коммерческий тариф Alibaba, весов нет | ❌ |
| `grok-4.3`, `grok-4.6` | закрытые | ❌ |

Реестр моделей для этого провайдера **не заводился**: проверить structured output и
приём картинок на нём не удалось, а класть в репозиторий конфиг, который не прогонялся
ни разу, — значит выдать непроверенное за готовое. Появится квота — добавится за пять минут,
модель там та же, что в `models.groq.yaml`.

### Groq: бесплатно, быстро и по правилам

`qwen/qwen3.8-27b` — веса `Qwen/Qwen3.8-27B`, apache-2.0, 27.8B, `image-text-to-text`.
Одна модель закрывает обе роли: и планирование с композицией, и VLM-судью, потому что
принимает картинки. Structured output работает.

Скорость: **0.3–0.4 с** на вызов против 2–3 с у прочих и 22–56 с у Cloudflare.

Ограничитель — не запросы, а токены: **8000 в минуту** (запросов 1000 в сутки).
Классификация макетов шаблона VK Education заняла 14 вызовов и **323 с** — почти всё это
время клиент ждал сброса лимита. Для отладки годится, для живого демо — нет.

Есть ещё `openai/gpt-oss-20b` (apache-2.0, 20.9B), но он текстовый: для аудита слайдов
не подойдёт. `gpt-oss-120b` не проходит по размеру.

### Cloudflare Workers AI: единственный источник открытой Mistral Small

`@cf/mistralai/mistral-small-3.1-24b-instruct` — веса
`mistralai/Mistral-Small-3.1-24B-Instruct-2503`, apache-2.0, 24B, картинки принимает,
отвечает за 2–3 с. Это то, чего **не даёт сам Mistral через свой API**.

Также `@cf/qwen/qwen3.8-27b` (работает, но 22 с на текст и 56 с на картинку — держать
запасным) и `@cf/qwen/qwen3-30b-a3b-fp8` (3 с, картинок не принимает).

Бесплатный тариф — 10 000 «нейронов» в сутки. Учётные данные R2 из того же аккаунта
пригодятся под артефакты вместо MinIO (change 23).

### Бесплатных провайдеров с пригодными моделями не существует

Это верно для роутеров-агрегаторов, но **не** для Groq и Cloudflare, которые раздают
открытые модели по собственному бесплатному тарифу (см. выше).

* **Роутер HuggingFace:** 332 пары модель×провайдер, из них `is_free: true` — **ноль**.
  «Бесплатность» здесь означает месячный лимит кредитов на аккаунт. На выданном токене
  он был исчерпан: примерно половина вызовов возвращала `402`.
* **OpenRouter:** 446 моделей, бесплатных — 23. Среди них ни одной пригодной: это Claude,
  GPT, Gemini, Grok и GLM, то есть закрытые веса либо больше 35B.

### Провайдер важнее модели

У одной и той же `Qwen/Qwen3.8-27B` на роутере HuggingFace structured output поддерживают
`deepinfra`, `ovhcloud` и `cerebras`, и **не поддерживает** `novita`. Роутер выбирает
провайдера сам, поэтому без пина поведение случайно: то схема работает, то нет.
Отсюда поле `provider` в `ModelSpec`.

### Mistral: открытых версий больше не отдаёт

Веса `Mistral-Small-3.2-24B-Instruct-2506` (Apache-2.0, 24B), `Magistral-Small-2509`
(Apache-2.0, 24B) и `Pixtral-12B-2409` (Apache-2.0) по правилам проходят. Но в каталоге
API их нет: `mistral-small-latest` указывает на `mistral-small-2603`, у которого
репозитория весов не существует (HF отвечает 401). То есть через API доступны только
закрытые версии — использовать нельзя. Бесплатный тариф вдобавок отдаёт `429`
с первого же запроса.

`Ministral-8B-Instruct-2410` отпадает отдельно: лицензия `other`, не Apache и не MIT.

### Как проверять провайдера за пять минут

1. Взять список моделей у провайдера.
2. Для каждой найти репозиторий весов на HuggingFace. Нет репозитория — модель закрытая,
   дальше можно не смотреть.
3. Проверить лицензию (`apache-2.0` или `mit`) и число параметров (`safetensors.total`).
4. И только потом — цену, скорость и поддержку structured output.

Порядок важен: и Mistral, и MuleRouter выглядят подходящими ровно до второго шага.

### MuleRouter: 17 моделей Qwen, и ни одной с открытыми весами

Эндпоинт OpenAI-совместимый (`https://api.mulerouter.ai/vendors/openai/v1`), ключ рабочий,
ответы приходят. Но в каталоге из 32 моделей все 17 «Qwen» — это коммерческие тарифы
Alibaba: `qwen-plus`, `qwen-max`, `qwen-flash`, `qwen-vl-max`, `qwen3-max`, `qwen3-vl-plus`,
`qwen3.6-flash` и подобные. Весов у них нет: HuggingFace на `Qwen/Qwen3-Max`,
`Qwen/Qwen3-VL-Plus`, `Qwen/Qwen3.6-Plus` отвечает 401 — репозиториев не существует.

Открытых релизов, которые называются по числу параметров (`Qwen3-32B`, `Qwen3-30B-A3B`,
`Qwen3-VL-8B`), в каталоге нет вовсе.

Это тот же капкан, что и у Mistral: **имя семейства не означает открытых весов**.
Проверять надо не название модели у провайдера, а наличие репозитория весов и лицензию.
Остальные модели каталога — `deepseek-v4-*`, `glm-5.1`, `kimi-k2.6`, GPT и Claude — тоже
мимо: либо закрытые, либо больше 35B.

### YandexGPT и x.ai Grok: дисквалифицируют

YandexGPT — проприетарная модель, весов нет в принципе.

У x.ai веса есть только у старых версий: `xai-org/grok-1` действительно под apache-2.0,
но это 314B — втрое больше потолка в 35B. У `grok-4` и `grok-4.20` репозиториев весов
не существует. Никакой тариф этого не меняет.

## Как переключаться

Все пригодные провайдеры говорят по протоколу OpenAI, поэтому переключение — это
переменные окружения и выбор реестра моделей. Код модель по имени нигде не называет.

```bash
# локально и бесплатно
ollama pull qwen3:8b && ollama pull qwen3-vl:8b
export DECKFORGE_MODELS_CONFIG=models.ollama.yaml
export DECKFORGE_LLM_BASE_URL=http://localhost:11434/v1 DECKFORGE_LLM_API_KEY=ollama
export DECKFORGE_VLM_BASE_URL=http://localhost:11434/v1 DECKFORGE_VLM_API_KEY=ollama

# OpenRouter
export DECKFORGE_MODELS_CONFIG=models.openrouter.yaml
export DECKFORGE_LLM_BASE_URL=https://openrouter.ai/api/v1 DECKFORGE_LLM_API_KEY=sk-or-...
```

Ключи — только в `.env`, который в `.gitignore`. В репозиторий не коммитятся никогда.

## Что это значит для плана

Отладка идёт на локальном Ollama, замеры качества — на облаке за деньги (нескольких
долларов хватает с запасом), финал — на инференсе VK, который топ-10 даёт бесплатно.
Переключение между всеми тремя ничего в коде не меняет.
