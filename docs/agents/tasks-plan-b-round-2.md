## Корни и changes

### К1. Грамматика `maxLength` режет слово — поток A (+ C)
Все 7 обрезанных текстов ровно длины предела места (`len == capacity_chars`): модель
не уложилась, грамматика llama.cpp оборвала на знаке. Замер после этого видит «влезший»
текст и не зовёт повтор. Это ровно то, что показала проба #243: одна схема без текста режет.

* **A — `the-limit-is-not-a-guillotine`.** В схеме — предел с запасом (`maxLength` ≈ 1,5 ×
  ёмкость, не меньше предела + самое длинное слово фактов), настоящий предел — в тексте промпта
  (он и сейчас там). Текст длиннее места ловит уже существующий замер → один повтор → обрезка
  **по словам** с заметкой. Ответ длиной ровно `maxLength` — считать оборванным: повтор.
* **C — `the-cut-word-is-found`.** Проверка по IR: текст места длиной ровно своего предела
  схемы и последнее слово не словарное (LanguageTool уже есть) — находка. В мерило — строка 6б.

Мерило: обрезанных посреди слова — 0 на трёх колодах.

### К2. Место «число» — не место для выдумки — поток A
Паспорт метит место числом по одному признаку — «держит меньше двух слов». Так числом
стали и **заголовки** (`slide_title` cap 8–16: обложка WorkSpace, `ex003`, `ex024`), и порядковые
номера карточек (`ex027` «01–04»), и подписи шкал (`ex052`). Модель, у которой в фактах нет
чисел, пишет «1».

* **A — `a-title-is-never-a-number`** (паспорт): место со ступенью заголовка (`slide_title`,
  `display` на обложке) — всегда текст; если держит меньше двух слов — пример не годится
  для слайда с утверждённым заголовком (К3).
* **A — `numbers-come-from-facts`** (назначение + композиция): место-число заполняется,
  только если у слайда есть факт с числом; нет — группа места не заказывается (`row_fill`,
  одиночное место — пусто, вёрстка снимет группу), а пример с обязательными числами
  назначается слайду с числами. Порядковый номер карточки («01») пишет код по порядку
  ряда, а не модель.

Мерило: `content.numbers_grounded` — 0; ни одного заголовка из одного знака.

### К3. Обложка и финал теряют факты — поток A
`assign_recipes` для `title`/`closing` берёт пример по виду («cover», «final»), не сверяя его
места с тем, что слайду нести: заголовок плана + подзаголовок/факты. `ex028` — одно место
«число», `ex041` — одно слово, `ex014` — место заголовка на 23 знака.

* **A — `the-cover-holds-its-facts`**: пример обложки/финала проходит тот же отбор по местам,
  что контентный: место заголовка держит утверждённый заголовок (после полосы места — #263),
  есть место под подзаголовок, если план дал факты. Нет такого — родственный вид, затем путь ДС.

Мерило: `integrity.content_lost` / `empty_slide` — 0.

### К4. Пример по смыслу — поток A
`ex052` (диаграмма Ганта) каталог назвал «text»: 12 крошечных мест — подписи полос и шкалы.
Проза разрезана по полосам.

* **A — в `a-title-is-never-a-number` или отдельно:** пример, у которого больше половины
  текстовых мест — места-числа или меньше трёх слов, не назначается слайду-прозе.

### К5. Слайд без примера — вёрстка ДС — поток B
Путь 5б работает (0 сплющенных, 0 снятых), но выглядит слабо — это 10 из 23 слайдов:

* **B — `a-node-never-breaks-a-word`**: подпись узла схемы не переносится по слогам — кегль узла
  по самому длинному слову (как у паспорта), не влезает и на пороге — меньше узлов в ряд (две
  строки процесса), затем `layout.object_overflow`.
* **B — `the-diagram-reads-on-its-fill`**: цвет узлов — один акцент ДС на схему (не циклом
  по слотам), текст на узле — из пар контраста (`text_ink`, как 5а для плашек).
* **B — `the-callout-keeps-off-the-title`**: решатель положений не кладёт выноску и схему
  в полосу заголовка (Education s02, s08); пустая плашка макета без блока — снимается
  или занимается блоком (VK Tech s02, s03, s05).

Мерило: `layout.object_overflow` — 0; перекрытий с заголовком — 0 (`layout.overlap`);
глазами — лист колоды (#258).

### К6. Контраст на плашке примера — поток B
5а меняет цвет нашего текста только когда цвет плашки известен. У WorkSpace плашки карточек
с `alpha`/`lumMod` — «цвет не судится», текст остаётся синим на тёмном.

* **B — `the-plate-with-alpha-is-judged`**: цвет плашки с `alpha` — смешение с фоном слайда
  (фон известен из `background`), `lumMod/lumOff` — по формуле OOXML. Текст, вылезающий
  за плашку, — по высоте места паспорта (строка 3 за это не отвечает).

Мерило: заметок «контраст не проверен» — 0 на трёх колодах; `template.contrast_below_wcag` — 0 находок.

### К7. Кэш шаблона — тимлид

Тимлид: поднять ответ llama.cpp в журнал (`warm_template_cache.py` печатает только счётчик),
