# ADR-007. Диапазон Python вместо жёсткого пина 3.12

**Статус:** принято, 15.09.2026

## Контекст

ARCHITECTURE.md §8.1 задаёт `requires-python = ">=3.12,<3.13"`. Образы и CI зафиксированы
на 3.12, но на машинах разработчиков стоит 3.13, и жёсткая верхняя граница ломает
любой локальный запуск инструментов.

## Решение

`requires-python = ">=3.12,<3.14"`. Целевая версия остаётся **3.12**: на ней собираются
образы (`docker/Dockerfile`), на ней гоняется CI, она указана в `[tool.mypy] python_version`.
Верхняя граница расширена только для совместимости окружений.

## Следствия

- Синтаксис и стандартная библиотека используются в пределах 3.12 — за этим следит mypy
  с `python_version = "3.12"`.
- Артефакт сдачи по-прежнему воспроизводится на 3.12 внутри образа, поэтому требование
  воспроизводимости не размывается.

## Условие пересмотра

Если появится зависимость, несовместимая с 3.13, граница возвращается к `<3.13`,
а разработка целиком уходит в контейнер.
