# the-third-row-is-measured

План Б, мерило. Капабилити `plan-b-acceptance`, тимлид. Эпик #242, после #255.

## Explore

Строка 3 таблицы приёмки — пустые карточки — стояла прочерком: считать было нечем.
Поток C добавил проверку `integrity.empty_group` (#255): на колоде VK Tech 28.09 —
16 пустых групп на 6 слайдах, ровно как на превью.

Сводить её в мерило по находкам `run.json` опасно одним: прогон, собранный кодом без этой
проверки, находок не имеет — и выглядел бы нулём. Это тихий ноль, от которого план Б
и уходил.

## Propose

* `run.json` SHALL перечислять проверки, зарегистрированные в коде прогона (`checks_known`).
* Строка 3 SHALL быть числом слайдов с находкой `integrity.empty_group`, если проверка
  есть в `checks_known` и не пропущена; иначе — прочерк.

## Verify

`tests/unit/test_the_third_row_is_measured.py`: три пустые группы на двух слайдах — два;
проверка шла без находок — ноль; кода без проверки и пропуск — прочерк; `run.json`
перечисляет проверки. На фикстурах 28.09 строка 3 — прочерк: их прогоны проверки не знали.

## Что осталось незакрытым

Число «до» по строке 3 из `run.json` 28.09 не получить — проверки тогда не было. Замер
потока C по колодам 28.09 (6 слайдов VK Tech) — в proposal #255.
