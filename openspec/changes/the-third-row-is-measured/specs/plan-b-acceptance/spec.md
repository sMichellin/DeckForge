# plan-b-acceptance

## ADDED Requirements

### Requirement: Строка 3 считается только там, где проверка шла
Отчёт прогона SHALL перечислять проверки, известные его коду. Строка 3 SHALL быть числом
слайдов с находкой пустой группы примера, если проверка известна коду прогона и не пропущена;
иначе SHALL стоять прочерк.

#### Scenario: Пустые группы
- **WHEN** в отчёте три находки пустой группы на двух слайдах
- **THEN** строка 3 — два

#### Scenario: Чистый прогон
- **WHEN** проверка известна коду прогона и находок нет
- **THEN** строка 3 — ноль

#### Scenario: Прогон старым кодом
- **WHEN** проверки нет среди известных коду прогона
- **THEN** строка 3 — прочерк
