# pptx-writer

## ADDED Requirements

### Requirement: Иллюстрация автора при паспорте остаётся
Группа паспорта, все места которой — картинки, SHALL оставаться на слайде: писатель ассет
в неё не ставит, и незаполненной она не бывает. Картинка внутри карточки с текстовыми местами
SHALL уходить вместе с незаполненной карточкой. Фигура остающейся группы SHALL NOT сниматься,
даже если её адрес есть и у уходящей группы.

#### Scenario: Слайд без текста в карточках
- **WHEN** у рецепта с паспортом есть группа из одной картинки, а IR заполняет только заголовок
- **THEN** картинка остаётся, незаполненные карточки уходят

#### Scenario: Фигура в двух группах
- **WHEN** адрес иллюстрации есть и в декоре незаполненной карточки
- **THEN** карточка уходит, иллюстрация остаётся
