# the-author-picture-stays

План Б, fix-forward к change 4 `the-writer-removes-whole-groups` (#257). Тимлид по поручению
владельца: поток B исправления не прислал, а #257 смержен без него (request changes стоял).
Файл — `rendering/recipe_slide.py` (поток B). Capability `pptx-writer`.

## Explore

При паспорте писатель снимает группу, в которой нет нашего текста. Картинку в рецептный слайд
он не ставит вовсе, поэтому группа из одних картинок — иллюстрация автора, которую
`build_passport` кладёт отдельной группой из `recipe.picture_xml_id`, — всегда выглядела
незаполненной и уходила. Путь `legacy` её оставлял: это регрессия против базы.

Замер по каталогам трёх шаблонов кейса (паспорта по фикстурам 28.09, `clone_recipe` каждого
примера с иллюстрацией, IR — две первые текстовые зоны): групп из одних картинок — 27
(VK Tech 12, Education 11, WorkSpace 4), картинок внутри карточек с текстом — 0.
До правки иллюстрация осталась на **0 из 27** примеров.

Второе: на Education `ex045` фигура 1001 — и картинка отдельной группы, и декор карточки `g03`.
Паспорт обязан держать фигуру ровно в одной группе (инвариант — следующий change A по паспорту);
пока он нарушен, уходящая карточка уносила иллюстрацию.

## Propose

* Группа, все места которой `PICTURE`, при паспорте **остаётся** (`_stays`). Картинка внутри
  карточки с текстовыми местами уходит вместе с незаполненной карточкой — как в change 4.
* Снятие в два прохода: сначала решается, какие группы остаются, затем снимаются фигуры
  уходящих, **кроме** фигур остающихся групп. Писатель не снимает то, что сам решил оставить.
* Путь `legacy` не затронут: эталоны XML change 4 сверяются байт в байт.

## Verify

`tests/unit/test_the_author_picture_stays.py` — 5 тестов: иллюстрация остаётся при IR только
с заголовком (норма, красный до правки); незаполненные карточки рядом уходят (нарушитель, красный
до правки); картинка в незаполненной карточке уходит с ней (нарушитель); в заполненной — остаётся
(норма); фигура, общая с уходящей карточкой, остаётся (нарушитель паспорта).

Замер после правки: иллюстрация осталась на **27 из 27** (VK Tech 12/12, Education 11/11,
WorkSpace 4/4). Строка 3 не меняется: `integrity.empty_group` картинок не считает.
Тесты change 4, 5а и `the-empty-card-is-found` — зелёные.
