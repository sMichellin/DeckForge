# the-deck-is-audited-offline

План Б, change 6б. Капабилити `pipeline-orchestration`, тимлид. Эпик #242.

## Explore

Потоки A и B мерят правку по колодам настоящего прогона. До этого change это значило
полный прогон на стенде (205–376 с) и ключ от стенда, которого у агентов может не быть.
`deckforge audit` был `NotImplementedError` (`cli.py`).

Прогон же оставляет всё нужное в `checkpoint.sqlite`: финальное состояние графа
по нити «прогон:вариант» читается API LangGraph (`aget_state`) — план, IR, контент,
манифест, дизайн-система. Проверено на трёх прогонах 28.09.

Запуск проверок по готовому контексту уже есть (`AuditRunner.run`). Не хватало только
чтения состояния.

## Propose

* `pipeline/replay.py`: `RunSnapshot` — план, IR, контент, манифест, дизайн-система,
  `run.json`; читается из каталога прогона (`from_checkpoint`) или фикстуры
  (`from_fixture`), пишется фикстурой (`save_fixture`, сжатый JSON, детерминированно).
* `reaudit(snapshot)` — детерминированный аудит без судьи и без превью; проверки, которым
  не хватило превью или файла колоды, SHALL называться в `skipped_checks`.
* `deckforge audit <каталог прогона или фикстура>` вместо `NotImplementedError`.
* `scripts/export_run_fixture.py` — выгрузка прогона фикстурой.
* Фикстуры трёх колод 28.09 — `tests/fixtures/runs/2026-09-28/`, 248 КБ.

Файлы `.pptx` в фикстуры не входят: колоды 9–18 МБ, шаблоны 13–24 МБ, и шаблоны заказчика
в репозиторий не кладутся. Где их взять — `tests/fixtures/runs/README.md`.

## Verify

`tests/unit/test_the_deck_is_audited_offline.py` — 10 тестов: три фикстуры читаются
моделями; круг «выгрузка → чтение» без потерь и с одинаковыми байтами; переаудит
повторяем и называет пропущенное; мерило плана Б по фикстурам даёт базу «до»; каталог
без чекпойнта, чекпойнт без нити, папка без фикстуры — названные ошибки; CLI по фикстуре.

**Проверено на данных:**

* паспорта по фикстурам совпали с посчитанными по файлу шаблона: 29/29, 51/54, 45/45;
* переаудит на `plan-b` против аудита прогона 28.09: все находки переаудита совпали
  с находками прогона. Не повторились три группы, и каждая объяснена:
  * `template.size_not_in_scale` и `integrity.duplicate_slides` (16/10/1 и 6/6/0) —
    это исправления RG59 (#234) и RG61 (#235), влитые в `main` после прогона.
    Переаудит подтвердил их на настоящих колодах;
  * `template.sample_text_left`, `integrity.file_opens` — нет файла колоды, названы
    в `skipped_checks`;
  * `design.*` — нет превью, названы в `skipped_checks`.

Гейты: `ruff`, `mypy`, гейт констант, спек-покрытие, полный `pytest`.

## Что осталось незакрытым

* **Тихий ноль в `template.font_not_in_theme`** (поток C): без файла колоды она пропускает
  свою файловую часть молча, а не называет себя пропущенной. На Education прогон 28.09
  нашёл по файлу настоящую ошибку (3 гарнитуры), переаудит фикстуры её не видит — и не
  говорит об этом. Сообщено в #245.
* LangGraph предупреждает, что чтение доменных типов из чекпойнта (`AuditReport`,
  `AutoFix`) «будет заблокировано в будущей версии» без `allowed_msgpack_modules`.
  Касается и HITL-возобновления, не только снимка. Отдельная задача тимлида.
* Файлы `.pptx` — вне репозитория. Выкладывать ли шаблоны заказчика в релиз приватного
  репозитория — решение владельца.
