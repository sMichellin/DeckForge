# audit-deterministic

## ADDED Requirements

### Requirement: Слайд по рецепту сверяется с макетом своего рецепта
Проверка «слайд собран не на макете из шаблона» для слайда, собранного по рецепту
(`SlideIR.by_recipe`), SHALL сверять часть макета в файле с `part_name` рецепта этого
слайда, а не с макетом, объявленным планом. Рецепт без `part_name` SHALL проверку
пропускать. Для слайда не по рецепту поведение проверки SHALL остаться прежним.

#### Scenario: Слайд по рецепту лежит на макете своего примера
- **WHEN** слайд собран по рецепту `ex018`, у которого `part_name` равен `slideLayout13.xml`
- **AND** в файле слайд лежит на `slideLayout13.xml`
- **AND** план объявлял другой макет
- **THEN** находки нет

#### Scenario: Слайд по рецепту лежит не на макете своего примера
- **WHEN** слайд собран по рецепту `ex018` с `part_name` равным `slideLayout13.xml`
- **AND** в файле слайд лежит на `slideLayout02.xml`
- **THEN** находка есть
- **AND** в сообщении названы и рецепт, и обе части макета

#### Scenario: У рецепта не известна часть макета
- **WHEN** слайд собран по рецепту, у которого `part_name` не задан
- **THEN** находки нет

#### Scenario: Слайд собран по макету
- **WHEN** слайд не по рецепту и лежит не на том макете, что объявлял план
- **THEN** находка есть, как и прежде

### Requirement: Текст в зоне рецепта меряется вместимостью зоны
Проверка переполнения текста для блока с `zone_id` SHALL брать пределом
`capacity_chars` этой зоны, а не `capacity` макета. Пустой `fit_report` у слайда
по рецепту SHALL считаться не отсутствием замера, а замером каталога.

#### Scenario: Текст короче вместимости зоны
- **WHEN** блок стоит в зоне с `capacity_chars` равным 60
- **AND** в блоке 42 знака
- **AND** `fit_report` слайда пуст
- **THEN** находки нет

#### Scenario: Текст длиннее вместимости зоны
- **WHEN** блок стоит в зоне с `capacity_chars` равным 32
- **AND** в блоке 42 знака
- **THEN** находка есть
- **AND** в сообщении названа вместимость зоны, а не макета

#### Scenario: Блок без зоны на слайде по рецепту
- **WHEN** у блока нет `zone_id`
- **AND** у слайда пуст `fit_report`
- **THEN** предел берётся из `capacity` макета, как и прежде

#### Scenario: Замер вёрстки есть
- **WHEN** у блока есть запись в `fit_report`
- **THEN** проверка верит замеру и вместимости не считает
