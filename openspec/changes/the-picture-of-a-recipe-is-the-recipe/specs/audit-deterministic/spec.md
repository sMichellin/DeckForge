# audit-deterministic

## MODIFIED Requirements

### Requirement: Дубль слайдов по рецепту решается текстом
Проверка «два слайда дублируют друг друга» SHALL решать по тексту, если оба слайда пары
собраны по рецепту: перцептивный хеш такого слайда меряет композицию примера шаблона,
а не содержание. Порог SHALL быть тем же `text_cosine`, что при сравнении без превью.
Если хотя бы один слайд пары не по рецепту, SHALL решать картинка, как раньше.

#### Scenario: Один рецепт, разный текст
- **WHEN** оба слайда собраны по рецепту и их превью совпадают
- **AND** совпадение их текста ниже порога
- **THEN** находки нет

#### Scenario: Один рецепт, одинаковый текст
- **WHEN** оба слайда собраны по рецепту и их текст совпадает выше порога
- **THEN** находка есть
- **AND** в находке сказано, что сравнивался текст

#### Scenario: Слайды не по рецепту
- **WHEN** слайды собраны не по рецепту и их превью совпадают
- **AND** совпадение их текста ниже порога
- **THEN** находка есть, как раньше
