# audit-deterministic

## ADDED Requirements

### Requirement: Проверка гарнитур без файла колоды не отдаёт тихий ноль
Проверка `template.font_not_in_theme` SHALL называть себя пропущенной (`CheckUnavailable`,
запись в `skipped_checks`), если файла колоды нет и по IR нарушений не найдено: гарнитуры
текста видны только в `.pptx`, и пустой результат означал бы «проверено, чисто».
Находка по IR (гарнитур больше порога уже по плейсхолдерам) SHALL оставаться находкой
и без файла. Файл колоды, который не открылся, SHALL давать пропуск, а не пустой набор
гарнитур.

#### Scenario: Файла нет, по IR чисто
- **WHEN** аудит идёт без файла колоды, а гарнитур плейсхолдеров не больше порога
- **THEN** проверка в `skipped_checks`, находок и «пройдено» у неё нет

#### Scenario: Файла нет, по IR нарушение
- **WHEN** аудит идёт без файла колоды, а гарнитур плейсхолдеров больше порога
- **THEN** проверка отдаёт находку `too_many_families`

#### Scenario: Файл не открылся
- **WHEN** путь к колоде есть, но файл не читается как `.pptx`
- **THEN** проверка в `skipped_checks`

#### Scenario: Файл есть и набран гарнитурой шаблона
- **WHEN** файл колоды открылся, гарнитуры в нём из шаблона и их не больше порога
- **THEN** находок нет, проверка пройдена

#### Scenario: Переаудит фикстуры
- **WHEN** переаудит снимка прогона без `.pptx` (`tests/fixtures/runs/2026-09-28/*`)
- **THEN** `template.font_not_in_theme` названа в `skipped_checks`
