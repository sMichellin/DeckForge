## Explore

`template.font_not_in_theme` состоит из двух частей:

* по IR — гарнитуры плейсхолдеров, в которые легли блоки; их **число** против порога;
* по файлу — гарнитуры прогонов текста в `.pptx`: чужая гарнитура и лишние гарнитуры
  появляются только при записи.

Файловая часть стояла под `if ctx.deck_path is not None`. Без файла проверка отдавала
пустой список, прогон считал её **пройденной**, в `skipped_checks` её не было.
На Education прогон 28.09 нашёл по файлу настоящую ошибку (3 гарнитуры при 2 допустимых),
переаудит фикстуры — ноль и молчание.

Второй тихий ноль того же рода — `_fonts_in_file`: файл не открылся → `{}`, то есть
«гарнитур в файле нет». Соседние проверки файла (`sample_text_left`, `decor_leads_nowhere`)
в таком случае называют себя пропущенными.

## Propose

* Без файла и без находок по IR — `CheckUnavailable("файла колоды нет: …")`.
* Находка по IR без файла остаётся находкой: «нарушение есть» доказано и без файла,
  а «нарушений нет» — нет.
* Файл не открылся — `CheckUnavailable`, как у соседей.

## Проверка

`tests/unit/test_the_font_check_names_its_skip.py` — 5 тестов (правило 7):
нарушители — без файла чисто по IR, битый файл, переаудит Education (все три красные без
правки); нормы — находка по IR без файла, файл с гарнитурой шаблона. Прежний
`test_font_not_in_theme_silent_within_the_limit` (без файла ждал `[]`) теперь ждёт пропуск —
его норма с файлом уже есть рядом (`..._silent_when_file_uses_template_fonts`).

## Что осталось незакрытым

* Ошибку Education (3 гарнитуры) переаудит по-прежнему **не видит** — теперь честно
  говорит, что не смотрел. Увидит, когда `.pptx` колоды будет рядом со снимком
  (стенд или `../data/Датасет/`, `tests/fixtures/runs/README.md`).
* Тот же тихий ноль на **неоткрывшемся** файле ещё у двух проверок, здесь не правится
  (один change — одна находка): `layout.image_aspect_distorted` (`layout.py`, `except
  Exception: return`) и `template.layout_not_from_template` (`_layout_parts_in_file`
  отдаёт `None`). Без файла вовсе обе уже называют себя пропущенными; тихо только
  при битом файле. Предлагаю отдельным change'ем.
