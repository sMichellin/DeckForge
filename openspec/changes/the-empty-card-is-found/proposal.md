Capability: `audit-deterministic`. Статус: implemented, ждёт ревью (28.09).
Ветка `feat/the-empty-card-is-found` от `origin/plan-b`, PR — в `plan-b`.
Файлы (C): `audit/deterministic/integrity.py`, `audit/recipes.py`, `configs/audit_checks.yaml`,

Корень плана Б — 3 («копируем пример целиком, потом угадываем, что удалить»): проверка
меряет, что от угадывания осталось на слайде. Строка приёмки 3, «до» — 6 слайдов VK Tech
(план Б, по превью). Строку сейчас не считает никто: судья-VLM видел пустые карточки на
5 слайдах из 10, детерминированные проверки молчали (RG36: пустая у автора рамка —
его композиция).

(`tests/fixtures/runs/2026-09-28/*`, шаблоны — `tests/fixtures/templates/`): `.pptx` стенда
у потока C нет. На каждом слайде по рецепту — группы паспорта (`with_passports` по снимку)
против фигур страницы по `cNvPr id`.

**По паспорту** — ровно то, что видно на превью:

|---|---|---|
| VK Tech | **6** | `ex018` на s02, s03, s04, s05, s07, s09: 2–3 карточки ряда с плашкой и без текста, у s02–s04, s09 ещё широкая карточка |

**По повторам каталога** (`repeat_xml_ids`, путь `legacy` из постановки) — **ноль** на VK Tech.
Каталог принял у `ex018` за повтор ряд, а не карточку (17 и 13 фигур на «повтор», это и нашёл

повторам строку 3 не сдвинула бы: она не видит того, что видно глазами.

## Propose

`integrity.empty_group` (`warning`, как `template.decor_leads_nowhere` до стенда):

* **Паспорт.** Из дизайн-системы контекста; у рецепта его нет — считается
  `with_passports(ds, manifest)` по тому же снимку (1–2 с на шаблон, один раз на аудит).
  Группы строятся по геометрии примера, шрифты влияют только на то, пройдёт ли пример пробную
  заливку.
* **Находка** — группа, у которой в файле осталась хоть одна фигура (декор или рамка места),
  а все текстовые места пусты. Одна находка на группу, `evidence`: рецепт, группа, ряд.
* **Не находка:** группа снята целиком; хоть одно место с текстом; все места пусты и у автора
  (`text_len` примера = 0, RG36); картинка-группа (текстовых мест нет).
* **Без паспорта** (пример не прошёл пробную заливку) — по `repeat_xml_ids`: повтор остался,
  в зонах повтора текста нет.
* **Пропуск:** нет файла, нет слайдов по рецепту, файл не открылся, страниц меньше, чем слайдов IR.

Проверка не импортирует писателя (замер не подтверждает сам себя): группы — из паспорта,
контракта A ↔ B, фигуры — со страницы файла.

идёт 2–8 с на колоду, из них паспорт — 1–2 с на шаблон.

без рамки текста, рамка без текста, повтор каталога без паспорта, колода VK Tech 28.09;
нормы — заполненная карточка, снятая целиком, пустая у автора (RG36), без файла — пропуск.
