# title-yields-size

Правка change (17) `pipeline-orchestration`, узел `fit`. По прогону `5561f47fdd8f`.

Статус: proposed → applied

## Explore

Прогон упал на записи: `WriterError: s03/b03_title: переполнение, стратегия shorten`.
Из чекпойнта: заголовок «Существующие AI-инструменты…» — **два слова, минимум подрезки** —
в полосе 21,7 × 3,2 см кеглем 36 pt требует двух строк, а полоса держит одну с небольшим.

Сложились три верных по отдельности правила: композиция режет заголовок до двух слов,
ниже не опускается; вёрстка заголовок кеглем не уменьшает (иерархия); писатель блок
с переполнением не пишет. На стыке — колода, которая не пишется вовсе.

## Propose

Порядок уступок: **сначала слова, и только когда резать нечего — кегль.** Узел `fit`
после цикла сокращений опускает переполненный заголовок на ступень шкалы (не более двух)
и пишет об этом в отчёт: «кегль заголовка уменьшен 36 → 23,4 pt — сокращать было уже нечего».

Правило «заголовок не уменьшается» остаётся в силе, пока есть что сокращать. Колода,
которая не пишется, не защищает никакой иерархии.

## Verify

Два теста: заголовок из двух слов в узкой полосе уступает кегль и это попадает в заметки;
заголовок, который влезает, остаётся крупным. Полный набор 1078 passed.
