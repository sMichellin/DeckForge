# audit-deterministic

## ADDED Requirements

### Requirement: Рецепт слайда взят из каталога шаблона
Детерминированный аудит SHALL сверять `recipe_id` каждого слайда колоды с каталогом
композиций шаблона — `designsystem.derive(manifest).recipes`, тем же каталогом, которым
пользуется писатель. Каталог SHALL считаться один раз на вызов проверки. Слайд, названный
рецептом, которого в каталоге нет, SHALL давать находку `template.recipe_not_in_catalogue`
уровня `error` с `slide_id` и названным `recipe_id`. Слайд без `recipe_id` этой проверкой
НЕ SHALL учитываться.

#### Scenario: Модель назвала рецепт, которого у шаблона нет
- **WHEN** колода на шаблоне с каталогом `ex001…ex029` содержит слайд `s10`
  с `recipe_id` равным «L12_15_title_slide_closing_step_a»
- **THEN** проверка отдаёт ровно одну находку уровня `error`
- **AND** в находке `slide_id` равен `s10`, а `evidence.recipe_id` — названный рецепт

#### Scenario: Все рецепты из каталога
- **WHEN** каждый слайд колоды назван рецептом из каталога этого шаблона
- **THEN** находок нет

#### Scenario: Каталог пуст
- **WHEN** у шаблона нет слайдов-примеров и каталог композиций пуст
- **AND** слайд назван рецептом
- **THEN** этот слайд даёт находку: названный рецепт выдуман

### Requirement: Слайд не по рецепту при непустом каталоге — оговорка
Детерминированный аудит SHALL отмечать находкой `template.slide_without_recipe` уровня
`info` каждый слайд, собранный не по рецепту (`SlideIR.by_recipe` ложен), если каталог
композиций шаблона непуст. Это оговорка, а не ошибка. При пустом каталоге проверка SHALL
пропускаться через `CheckUnavailable`, а не считаться пройденной.

#### Scenario: Слайд по макету рядом со слайдами по рецепту
- **WHEN** каталог шаблона непуст
- **AND** слайд `s03` собран по макету, без `recipe_id`
- **THEN** проверка отдаёт находку уровня `info` на `s03`
- **AND** слайды по рецепту находок не дают

#### Scenario: Все слайды по рецептам каталога
- **WHEN** каждый слайд колоды собран по рецепту из каталога
- **THEN** находок нет

#### Scenario: Каталога нет
- **WHEN** каталог композиций шаблона пуст
- **THEN** проверка поднимает `CheckUnavailable`
