# web-ui

## ADDED Requirements

### Requirement: Лист колоды рядом с примерами шаблона
Интерфейс SHALL показывать по готовому прогону лист колоды: для каждого слайда — его превью
и превью слайда-примера шаблона, по которому он собран (`slide_choices[].recipe_id`), вместе
с причиной выбора и числом слайдов колоды на этом примере. Пример, стоящий больше чем на
двух слайдах или на двух соседних, SHALL быть назван над листом. Находки
`integrity.empty_group` SHALL показываться у своего слайда. Лист SHALL строиться из файлов
прогона и кэша шаблона — без модели и без рендера.

Сервис SHALL отдавать превью слайда-примера по `GET /runs/{id}/examples/{recipe_id}`:
страница ищется в порядке показа слайдов шаблона прогона, скрытые слайды пропускаются.
Нет превью в кэше, нет такого примера или идентификатор не вида `ex<номер>` — 404.

#### Scenario: Слайд по рецепту
- **WHEN** слайд собран по примеру `ex018`, превью слайда и примера есть
- **THEN** в строке листа оба превью, причина выбора и «ex018 — на 6 слайдах из 10»

#### Scenario: Один пример на многих слайдах
- **WHEN** пример стоит больше чем на двух слайдах колоды или на двух соседних
- **THEN** над листом он назван с числом и номерами слайдов

#### Scenario: Слайд по макету
- **WHEN** у слайда нет рецепта
- **THEN** в строке превью слайда и «по макету L…», превью примера нет

#### Scenario: Превью примера нет в кэше
- **WHEN** примеры шаблона не рендерились (нет LibreOffice, холодный кэш)
- **THEN** сервис отвечает 404, лист показывает слайд без примера и не падает

#### Scenario: Чужой путь в идентификаторе
- **WHEN** запрос `GET /runs/{id}/examples/../../x`
- **THEN** 404, файл вне кэша не отдаётся
