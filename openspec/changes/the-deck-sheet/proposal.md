# the-deck-sheet

План Б, шаг 6 («быстрый просмотр»), поток C — задача 2 из #245 (эпик #242).
Capability: `web-ui` (+ маршрут сервиса). Статус: implemented, ждёт ревью (28.09).
Ветка `feat/the-deck-sheet` от `origin/plan-b`, PR — в `plan-b`.
Файлы (C): `api/app.py`, `api/store.py`, `api/jobs.py`, `frontend/app.py`, `frontend/client.py`,
`frontend/sheet.py` (новый).

Корень плана Б — 2 («пример выбирается по одному слайду, на колоду целиком никто не смотрит»)
и 3. Строки приёмки 1–3 глазами: пример по смыслу, повтор примера, пустые карточки.
Мерило — Д1 и правило «лист PNG рядом с примерами, а не число ошибок аудита».

## Explore

* Превью слайдов прогона уже есть: `out/previews/*.png` и указатель `out/previews.json`
  (`slide_id` → файл), маршрут `GET /runs/{id}/previews/{slide_id}`.
* Превью слайдов-примеров шаблона рендер кладёт в кэш один раз на шаблон:
  `<artifacts>/template-cache/example-previews/<template_id>/*.png`
  (`pipeline/nodes/render.py`, `EXAMPLES_DIR`; кэш задаёт `api/jobs.py`). Сервис о них не знал,
  в `run.json` их нет.
* Какой пример на каком слайде — `run.json` → `slide_choices[]`: `recipe_id`, `why`.
  `recipe_id` — `ex<номер части slideN.xml>`.
* Страница примера в PDF — в **порядке показа** и без скрытых слайдов, а номер примера —
  номер части. На шаблонах кейса они совпадают (54, 29, 55 слайдов, скрытых нет), на холодном
  не обязаны: страница ищется по `presentation.xml` шаблона прогона.
* Интерфейс показывает «почему такие слайды» текстом (Т7) — без картинок, повторы не видны.

## Propose

* **Сервис:** `GET /runs/{id}/examples/{recipe_id}` → PNG страницы примера из кэша.
  `template_id` — хэш загруженного шаблона (`template_id_of`), страница — порядок `sldIdLst`
  без `show="0"`; всё чтением zip, без python-pptx и без рендера. 404: нет кэша, нет примера,
  `recipe_id` не вида `ex\d+`; путь проверяется на принадлежность кэшу.
* **Лист** (`frontend/sheet.py`, чистые функции с тестами): строки по `slide_choices` —
  слайд, пример, причина, сколько слайдов колоды на этом примере; предупреждения над листом —
  пример больше чем на двух слайдах или на соседних (строка 2); находки
  `integrity.empty_group` у своего слайда (строка 3, #255).
* **Интерфейс:** раскрывающийся блок «Лист колоды» у готового прогона: слайд | пример | подпись.

## Verify

**Мерило на прогоне 28.09 VK Tech.** Стенда у потока C нет, поэтому каталог прогона собран
локально, как его раскладывает стенд: колода пересобрана писателем `plan-b` из IR фикстуры,
колода и шаблон отрендерены LibreOffice, `run.json` — из фикстуры, находки строки 3 —
из переаудита #255. Лист через настоящий сервис (`TestClient`):

* над листом: «ex018 — на 6 слайдах из 10: s02, s03, s04, s05, s07, s09» и три пары соседей;
* 10 слайдов, у всех найдены и превью слайда, и превью примера (страницы 54 примеров);
* глазами: слева слайд, справа `ex018` — сетка из пяти карточек, и видно, какие карточки
  на слайде пустые (s05: заполнена одна из пяти); обложка против `ex001`, финал против `ex006`;
* лист целиком — 0,6 с, без модели и рендера.

`tests/unit/test_the_deck_sheet.py` — 13 тестов: лист VK Tech 28.09 (6 из 10, соседи), пустые
карточки у своего слайда, разнообразная колода без предупреждений, склонение подписи, слайд
по макету, отчёт без выбора; сервис — страница за скрытым слайдом, превью примера, 404 на
чужой идентификатор и путь наружу, 404 на холодный кэш.

## Что осталось незакрытым

* Глазами в Streamlit на стенде лист не смотрели — разметка проверена только локальным
  прогоном API; логика строк покрыта тестами.
* Превью примеров появляются, только если рендер их снял: профиль без превью
  (`run_deterministic: false`) или стенд без LibreOffice — лист покажет слайды без примеров.
* Две прежние ошибки mypy в `frontend/client.py` (`report`, `status` — `no-any-return`)
  не тронуты: CI гоняет mypy по `src`, правка не про них.
