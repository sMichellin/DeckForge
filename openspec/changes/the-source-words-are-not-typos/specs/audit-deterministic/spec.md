# audit-deterministic

## MODIFIED Requirements

### Requirement: Слово из исходного материала не опечатка
Проверка «текст без опечаток» SHALL не выдавать находку орфографического правила
LanguageTool на слове, которое есть в исходном материале прогона — в `raw_markdown`
контент-пакета или в тексте его фактов. Слово SHALL сравниваться без учёта регистра
и с поправкой на окончание, но по основе не короче пяти букв. Находки грамматики
и пунктуации SHALL выдаваться как раньше, и на словах из материала тоже.

#### Scenario: Термин задания
- **WHEN** LanguageTool отмечает «дизайн-систему» как орфографическую ошибку
- **AND** в исходном материале есть «дизайн-систему»
- **THEN** находки нет

#### Scenario: Другая форма того же слова
- **WHEN** в колоде «дизайн-систему», а в материале «дизайн-система»
- **THEN** находки нет

#### Scenario: Слова нет в материале
- **WHEN** LanguageTool отмечает орфографическую ошибку на слове, которого в материале нет
- **THEN** находка есть

#### Scenario: Пунктуация на слове из материала
- **WHEN** LanguageTool отмечает пропущенную точку перед словом «Выделить»
- **AND** «выделить» есть в материале
- **THEN** находка есть

#### Scenario: Короткая основа
- **WHEN** слово совпадает с материалом только основой короче пяти букв
- **THEN** находка есть

#### Scenario: Материала нет
- **WHEN** проверка вызвана без контент-пакета
- **THEN** орфографическая находка выдаётся как раньше
