# web-ui

## ADDED Requirements

### Requirement: Варианты «все сразу» идут одновременно
Воркер SHALL вести одновременно не меньше прогонов, чем вариантов вёрстки (по умолчанию три),
чтобы «все варианты сразу» не ставили последний вариант в очередь. Число SHALL задаваться
переменной окружения `DECKFORGE_WORKER_MAX_JOBS`.

#### Scenario: Все три варианта
- **WHEN** интерфейс поставил три прогона разом
- **THEN** все три в состоянии «идёт», ни один не ждёт в очереди воркера

#### Scenario: Машина с малой памятью
- **WHEN** задано `DECKFORGE_WORKER_MAX_JOBS=1`
- **THEN** воркер ведёт один прогон, остальные ждут очереди
