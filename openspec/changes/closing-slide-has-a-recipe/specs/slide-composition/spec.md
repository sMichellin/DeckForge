# slide-composition

## ADDED Requirements

### Requirement: Структурный слайд не остаётся без композиции шаблона
Слайд, чьё место в колоде задаёт вид композиции (`TITLE`, `SECTION`, `CLOSING`),
SHALL получать рецепт своего вида; нет такого вида в каталоге — рецепт родственного
вида; нет и его — любой вмещающий содержательный рецепт. `None` SHALL возвращаться
только при пустом каталоге или когда ни один рецепт каталога не вмещает содержание
слайда. Откат SHALL называться в `notes` прогона.

#### Scenario: В шаблоне нет вида final
- **WHEN** слайд с `intent` равным `CLOSING`
- **AND** в каталоге есть виды `cover`, `section`, `text`, `cards`, `text_with_picture`,
  но нет `final`
- **THEN** слайд получает рецепт вида `section`
- **AND** в `notes` сказано, что вида `final` в шаблоне нет и какой рецепт взят вместо него

#### Scenario: В шаблоне нет ни final, ни section, ни cover
- **WHEN** слайд с `intent` равным `CLOSING`
- **AND** в каталоге только содержательные виды
- **THEN** слайд получает вмещающий содержательный рецепт
- **AND** откат назван в `notes`

#### Scenario: Вид слайда в каталоге есть
- **WHEN** слайд с `intent` равным `CLOSING`
- **AND** в каталоге есть рецепт вида `final`
- **THEN** слайд получает рецепт вида `final`
- **AND** откат не выполняется и в `notes` о нём ничего нет

#### Scenario: Каталог пуст
- **WHEN** у шаблона не извлечён ни один рецепт
- **THEN** рецепт равен `None`
- **AND** слайд собирается прежним путём — по макету

#### Scenario: Ни один рецепт не вмещает слайд
- **WHEN** слайд с `intent` равным `CLOSING`
- **AND** в каталоге нет ни `final`, ни `section`, ни `cover`
- **AND** все содержательные рецепты требуют картинку, а ассета у слайда нет
- **THEN** рецепт равен `None`
- **AND** в `notes` сказано, что ни один рецепт каталога слайд не вмещает

### Requirement: Родство видов структурных слайдов задано таблицей
Родственный вид структурного слайда SHALL браться из таблицы, а не выводиться
эвристикой: для `TITLE` — `section`, для `SECTION` — `cover`, для `CLOSING` —
`section`, затем `cover`.

#### Scenario: У шаблона нет обложки
- **WHEN** слайд с `intent` равным `TITLE`
- **AND** в каталоге есть `section`, но нет `cover`
- **THEN** слайд получает рецепт вида `section`

#### Scenario: У шаблона нет разделителя
- **WHEN** слайд с `intent` равным `SECTION`
- **AND** в каталоге есть `cover`, но нет `section`
- **THEN** слайд получает рецепт вида `cover`

#### Scenario: Закрывающему доступны оба родственных вида
- **WHEN** слайд с `intent` равным `CLOSING`
- **AND** в каталоге есть и `section`, и `cover`, но нет `final`
- **THEN** слайд получает рецепт вида `section`
