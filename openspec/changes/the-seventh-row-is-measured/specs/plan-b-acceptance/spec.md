# plan-b-acceptance

## ADDED Requirements

### Requirement: Строка 7 считается по файлу колоды
Мерило SHALL считать блоки ниже порога читаемости по файлу колоды, если он лежит рядом
с отчётом прогона; блок — пара «слайд, фигура». Без файла строка SHALL быть прочерком.

#### Scenario: Рамка ниже порога
- **WHEN** в колоде рамка 9 pt из двух прогонов текста при пороге 10 pt
- **THEN** строка 7 — один блок

#### Scenario: Читаемая колода
- **WHEN** все рамки не ниже порога
- **THEN** строка 7 — ноль

#### Scenario: Нет файла колоды
- **WHEN** рядом с отчётом нет `out/deck.pptx`
- **THEN** строка 7 — прочерк
