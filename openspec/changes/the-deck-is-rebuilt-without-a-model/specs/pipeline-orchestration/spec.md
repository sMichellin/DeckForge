# pipeline-orchestration

## ADDED Requirements

### Requirement: Колода пересобирается из чекпойнта без модели
Система SHALL пересобирать колоду готового прогона без модели: план и текст слайдов берутся
из чекпойнта (точка перед `fit`), вписывание, запись, аудит, фиксы и экспорт — текущим кодом.
Исходный прогон SHALL NOT изменяться; результат SHALL иметь раскладку прогона стенда.

#### Scenario: Пересборка прогона
- **WHEN** `deckforge rebuild` запущен на каталоге прогона с чекпойнтом
- **THEN** в новом каталоге есть колода и `run.json`, текст слайдов тот же, модель не вызывалась

#### Scenario: Нечего пересобирать
- **WHEN** в каталоге нет чекпойнта
- **THEN** ошибка называет недостающий файл
