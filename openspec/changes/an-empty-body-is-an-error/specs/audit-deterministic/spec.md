# audit-deterministic

## ADDED Requirements

### Requirement: Обложка и финал из одного заголовка — пустое тело
Проверка `integrity.empty_slide` SHALL давать находку на слайде, где нет ни одного блока,
кроме заголовка, если слайд — обложка или финал: по виду рецепта (`cover`, `final`), а без
рецепта — по виду макета (`title`, `closing`), даже если у макета нет места под тело.
Слайд-раздел (рецепт или макет вида `section`) из одного заголовка на макете без места
под тело SHALL NOT давать находку: он и есть строка между частями колоды.

#### Scenario: Обложка по примеру из одного заголовка
- **WHEN** на слайде по рецепту вида `cover` только заголовок, у макета места под тело нет
- **THEN** находка `integrity.empty_slide` «обложка или финал из одного заголовка»

#### Scenario: Финал без рецепта
- **WHEN** на макете вида `closing` только заголовок
- **THEN** находка `integrity.empty_slide`

#### Scenario: Раздел из одного заголовка
- **WHEN** на слайде вида `section` только заголовок
- **THEN** находок нет

#### Scenario: Обложка со строкой
- **WHEN** у обложки есть заголовок и строка о колоде
- **THEN** находок нет

#### Scenario: Прогон a3a8f3a2319b
- **WHEN** обложка s01 на `ex014` (макет `L09`) — один заголовок
- **THEN** находка `integrity.empty_slide`
