# pipeline-orchestration

## ADDED Requirements

### Requirement: Сдача проверяется прогоном через интерфейс
Репозиторий SHALL содержать сценарий прогона через UI (`scripts/ui_e2e.py`, `make ui-e2e`):
загрузка шаблона и материала, сборка, лист колоды, скачивание каждого формата кнопкой страницы.
Прогон SHALL считаться удавшимся, только если колода готова, pptx, pdf и html скачаны непустыми,
а на странице и в консоли браузера нет ошибок. Адрес сервиса `localhost` на странице, открытой
с другой машины, SHALL считаться находкой.

#### Scenario: Колода скачана через UI
- **WHEN** прогон через UI дошёл до кнопок «Скачать» и все три формата скачаны непустыми
- **THEN** итог — `passed: true`, код выхода 0

#### Scenario: Формат не скачался
- **WHEN** один из форматов не скачан или пустой
- **THEN** итог называет его в `missing_formats`, код выхода 1

#### Scenario: Адрес сервиса недоступен снаружи
- **WHEN** страница открыта по внешнему адресу, а поле «Адрес сервиса» — `localhost`
- **THEN** находка в `page_problems`
