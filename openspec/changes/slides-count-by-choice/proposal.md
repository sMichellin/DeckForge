## Explore

Заметка 26.09: «Необходимо сделать на выбор: можно выбрать количество слайдов итоговой
презентации, или нейронка сама подбирает оптимальное».

Сейчас `Brief.target_slides` обязателен, в интерфейсе — поле с 12 по умолчанию. Число
работает **потолком**: `planning.slides_for` урезает его по фактам (три на слайд плюс
титул и финал), и прогон пишет в `notes` «слайдов 8 вместо запрошенных 12». Интерфейс
`notes` не показывает — только `degradations` и `errors`, — так что для человека число
просто разошлось с заданным без объяснения. Режима «подбери сам» нет.

## Propose

1. **Бриф**: `target_slides: int | None = None` — `None` означает автоматический режим.
   Старые брифы с числом работают как раньше. `make schemas` — одна golden-схема
   `content_package` (поле перестало быть обязательным).
2. **Планирование**: `decide_slides(content, purpose, requested) -> SlidesDecision` —
   режим, заданное, число, причина словами. `slides_for` — его число, поведение
   точного режима прежнее. Автоматический: факты по три на слайд плюс титул и финал,
   не больше 15 (`AUTO_MAX_SLIDES`, верх 10–15 из ТЗ), снизу — каркас назначения,
   без добивки полупустыми слайдами до 10. Промпт в автоматическом режиме получает
   подобранное число вместо `None` — промпт не меняется, меняется то, что в него
   подставлено.
3. **Отчёт**: `slides_decision` в состоянии и в `run.json` — `mode`, `requested`, `count`,
   `planned` (сколько дал план), `reason`.
4. **API**: `target_slides: null` — автоматический режим; поле не передано — прежние 12.
5. **Интерфейс**: переключатель «Подобрать автоматически / Задать», причина — подписью
   под числом слайдов в сводке прогона.

## Проверка

`tests/unit/test_slides_count_by_choice.py` — 11 тестов по сценариям дельты: точный
режим (хватает, не хватает — нарушитель прежнего поведения, ниже каркаса), автоматический
(по материалу, верх 15, тонкий материал не добивается), бриф без числа, промпт получает
число, API и интерфейс передают `None`, сквозной прогон графа — `run.json` называет
решение.

## Что осталось незакрытым

* Интерфейс проверен тестом функции выбора, не глазами: живого Streamlit локально нет.
* `RunConfig.target_slides` (`config.py`) по-прежнему число 12 и не используется
  планированием — поле старое, здесь не трогалось.
* План модели может дать не то число, что подобрал счёт: `planned` в отчёте это покажет.
  Дотягивать план до числа — отдельный вопрос планировщика.
