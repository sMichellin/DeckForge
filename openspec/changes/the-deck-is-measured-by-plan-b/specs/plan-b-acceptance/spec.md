# plan-b-acceptance

## ADDED Requirements

### Requirement: Таблица приёмки плана Б считается по отчёту прогона
Скрипт мерила SHALL по каталогам готовых прогонов печатать таблицу приёмки плана Б:
путь сборки, примеры по смыслу среди содержательных слайдов, самый частый пример и
соседние повторы, снятые, сплющенные и обрезанные кодом блоки. Метрики, которые скрипт
не считает, SHALL стоять прочерком, а не нулём.

#### Scenario: Обложка и финал
- **WHEN** у колоды обложка, два содержательных слайда и финал
- **THEN** «по смыслу» считается из двух слайдов

#### Scenario: Повтор примера
- **WHEN** один пример стоит на трёх слайдах, два из них подряд
- **THEN** максимум повторов — 3, соседних пар — 1

#### Scenario: Потери по заметкам
- **WHEN** в заметках прогона снятые, сплющенные и обрезанные блоки
- **THEN** каждая заметка попадает в свою строку, прочие заметки не считаются

#### Scenario: Чистая колода
- **WHEN** в заметках нет потерь
- **THEN** строки потерь — нули

### Requirement: Шаблоны заметок сторожатся по коду
Каждая фраза, по которой скрипт относит заметку к строке, SHALL стоять в коде, который
эту заметку пишет. Переформулированная заметка SHALL валить тест, а не обнулять строку.

#### Scenario: Фраза переформулирована
- **WHEN** фразы заметки больше нет в файле, который её пишет
- **THEN** тест сторожа красный
