# slide-composition

## ADDED Requirements

### Requirement: Ёмкость места мерится вписыванием колоды
Ёмкость места паспорта SHALL быть наибольшей длиной пробного текста, которую вписывание
колоды ставит в зону кеглем автора — без переполнения и без спуска по шкале.

#### Scenario: Ёмкость места
- **WHEN** в зону встают 90 знаков пробного текста и не встают 91
- **THEN** ёмкость места — длина пробного текста не длиннее 90 знаков

### Requirement: Карточка находится по подложке
Группа мест SHALL собираться по подложке — фигуре без текста, где лежат центры двух
и больше текстов. Без такой подложки группа SHALL браться по повтору каталога, иначе
текст — одиночная группа. Группы одной формы и одного размера SHALL образовать ряд.

#### Scenario: Сетка карточек с полоской под заголовком
- **WHEN** у каждой из трёх карточек подложка, полоска под заголовком и два текста
- **THEN** паспорт — ряд из трёх групп по два места, полоска — декор своей карточки

#### Scenario: Широкая карточка
- **WHEN** рядом с тремя карточками стоит карточка вдвое шире
- **THEN** ряд из трёх, широкая карточка — отдельная группа

#### Scenario: Карточки без подложки
- **WHEN** у карточек нет подложки, а каталог нашёл их повторами
- **THEN** ряд собирается по повторам каталога

### Requirement: Паспорт есть только у примера, который заливается
Место, не держащее двух слов, SHALL быть местом под число. Место, не держащее и знака,
SHALL оставлять пример без паспорта с названной причиной. Все места SHALL заливаться
пробным текстом разом; не встало хоть одно — паспорта нет, причина названа.

#### Scenario: Номер в карточке
- **WHEN** место держит три знака и не держит двух слов
- **THEN** место под число с ёмкостью в три знака

#### Scenario: Место без знака
- **WHEN** место не держит и одного знака
- **THEN** паспорта нет, причина называет зону

#### Scenario: Места не встают вместе
- **WHEN** по одному места встают, а все вместе — нет
- **THEN** паспорта нет, причина — пробная заливка

#### Scenario: Каталог с отчётом
- **WHEN** у одного рецепта примера нет в манифесте
- **THEN** у остальных паспорт, у этого — причина в отчёте
