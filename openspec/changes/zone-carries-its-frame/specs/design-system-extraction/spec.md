# design-system-extraction

## ADDED Requirements

### Requirement: Зона рецепта несёт рамку фигуры примера
Каждая зона рецепта каталога композиций SHALL нести рамку своей фигуры слайда-примера —
`x`, `y`, `cx`, `cy` в EMU, в координатах слайда, с учётом масштаба группы. Рамка SHALL
браться у разобранной фигуры примера как есть: не обрезаться по краю слайда и не
пересчитываться. Зона, сохранённая без рамки, SHALL по-прежнему читаться; такая зона
считается зоной без рамки.

#### Scenario: Текстовая фигура примера становится зоной
- **WHEN** у слайда-примера есть текстовая фигура с рамкой `x`, `y`, `cx`, `cy`
- **THEN** у зоны рецепта, построенной по этой фигуре, та же рамка

#### Scenario: Заголовок опознан по месту
- **WHEN** заголовок рецепта назначен самой крупной зоной верхней трети слайда
- **THEN** у зоны заголовка остаётся рамка её фигуры

#### Scenario: Фигура заведена за край слайда
- **WHEN** у фигуры примера `x` отрицательный
- **THEN** у зоны тот же отрицательный `x`, рамка не обрезана

#### Scenario: Дизайн-система из старого чекпойнта
- **WHEN** зона сохранена до появления рамки и полей `x`, `y`, `cx`, `cy` у неё нет
- **THEN** зона читается без ошибки
- **AND** считается зоной без рамки
