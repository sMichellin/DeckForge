# pptx-writer

## ADDED Requirements

### Requirement: Отсутствие замера не роняет колоду
Писатель НЕ SHALL обращаться к `SlideIR.fit_report` по ключу напрямую. Блок без записи
о вписывании SHALL получать кегль своей роли из типошкалы манифеста, а подмена SHALL
называться в `degradations`. Колода из десяти слайдов лучше отсутствия колоды.

#### Scenario: Блок без записи в отчёте о вписывании
- **WHEN** в `fit_report` нет записи для `block_id` текстового блока
- **THEN** блок пишется кеглем роли из `manifest.size_ladder_pt`
- **AND** в `degradations` появляется строка с `slide_id` и `block_id`
- **AND** `KeyError` не возникает

### Requirement: Рецепт вне каталога — названная ошибка, а не падение
Если слайд назван собранным по рецепту, а рецепта с таким `recipe_id` нет в каталоге
композиций, писатель SHALL отказать через `WriterError` с названием рецепта и слайда.
Молчаливый переход к сборке на пустом макете НЕ SHALL выполняться.

#### Scenario: Рецепта нет в каталоге
- **WHEN** `SlideIR.recipe_id` равен «L12_15_title_closing», а в каталоге только `ex001…ex029`
- **THEN** запись падает с `WriterError`
- **AND** текст ошибки содержит `slide_id` и названный `recipe_id`
