Правило из круга 2 — «длина ровно в предел и последнее слово не словарное» — даёт здесь
и промахи, и ложные находки:

* «презент», «новый», «пат», «мин» — словарные слова (подарок, шахматы, мина): по словарю
  не поймать; LanguageTool к тому же внешний сервис, и без него проверка молчала бы;
* «до мин» и «пат.» — **не** на пределе: модель сократила слово сама, чтобы уложиться;
* в местах-числах на пределе стоят целые «минуты» и «10x».

Отсюда два признака вместо одного:

1. **Предел места** — текстовое место, длина ровно ёмкость: грамматика оборвала (5 из 7).
2. **Оборванное слово** — последнее слово — начало слова материалов, а само в материалах
   не встречается (2 из 7 сверх первого признака). Падежные формы дают ложные находки
   («труд» при «труда», «процесс» при «процессов»), поэтому: ближайшее продолжение — от двух
   букв, и ни одно продолжение не есть падежное окончание.

Замер правила по фикстурам — ровно семь на 29.09, ни одной на 28.09 (`legacy`).

## Propose

`content.word_cut` (`error`, детерминированная) в `audit/semantic/grounding.py` — рядом со
сверкой чисел с материалами: оба признака судят текст слайда против контент-пакета.
Блоки: `TextBlock` и пункты `BulletsBlock`; предел — из паспорта **дизайн-системы прогона**
(`catalogue`), место-число по пределу не судится. Нет материалов — только первый признак.

Паспорт, посчитанный задним числом (`catalogue_with_passports`), для предела не годится:
модель прогона `legacy` его не видела, а ёмкость зависит от шрифтов машины. Первый CI
это показал — на Linux текст VK Tech 28.09 s09 случайно совпал с такой ёмкостью по длине.

Пять по пределу места, два — «оборванное слово» («до мин», «пат.»). По ходу замера правило

(«ИИ делает слайды сам» при «самостоятельно») — не обрывок.

`tests/unit/test_the_cut_word_is_found.py` — 14 тестов: нарушители — предел места, сокращённое
моделью слово (2), пункт списка, семь на 29.09; нормы — падежная форма, окончание, служебное
слово, целое слово, чужое слово, без материалов, текст короче предела, число в месте-числе,
ноль на 28.09. Счётчики проверок: 37 → 38, `content.*` 12 → 13.

## Ревью тимлида (два круга)

**Предел места — только с «последнего слова нет в материалах целиком».** После #269 схема
даёт полторы ёмкости, модель пишет свободно и законно попадает ровно в ёмкость; обрезка
по словам (`trimmed_to_fit`) тоже может дать ровно ёмкость целыми словами. Переаудит шести
прогонов стенда кодом этого PR до правки: WorkSpace `c950b5936b7a` s10 «Open-source для
слайдов» — ложная (23 знака, «слайдов» в материалах), s09 «0 мин» — верная. Первое ревью
я пропустил и чинил CI иначе (`35b5041`: предел — только из паспортов дизайн-системы прогона);
это правило остаётся, но ложную находку на `by_example` оно не убирает — нужны оба.

С правкой на 29.09 — **6 из 7**: «Паттерн под новый» выпадает — ровно в предел, но «новый»
в материалах целиком; оборвана фраза, а не слово, а строка 6б — про обрыв слова.

## Что осталось незакрытым

* Словари окончаний и служебных слов — русские и немного английских; колода на другом языке
  по второму признаку судится грубее. Первый признак (предел места) от языка не зависит.
* После `the-limit-is-not-a-guillotine` (поток A, `maxLength` с запасом) первый признак
  перестанет срабатывать по построению — обрыв будет по словам с заметкой. Тогда проверку
  стоит перемерить на новых прогонах.
* В мерило (`plan_b_metrics.py`, строка 6б) сводит тимлид — число находок уже в `run.json`
  (`findings_detail`).
