# the-first-row-counts-examples

План Б, мерило. Капабилити `plan-b-acceptance`, тимлид. Замечание потока A к #248.

## Explore

Строка 1 таблицы приёмки считала «пример по смыслу» всё, чья причина выбора не начинается
словами «заказанного вида нет». Слайд, честно ушедший путём дизайн-системы без примера
(ADR-009, схема или callout без своего вида), под это определение тоже попадал. Значит,
строку можно было выполнить, не назначив ни одного примера. На замере #248 разница видна:
«по смыслу» 24 из 24, а пример получили 17.

## Propose

Строка 1 SHALL раскладываться на три числа содержательных слайдов:

* **пример по местам, а не по смыслу** — то, что лечит план Б; цель 0;
* **с примером по смыслу**;
* **путём дизайн-системы, без примера** — `recipe_id` пуст, причина не «по местам».

Цель по «с примером» задаёт тимлид после первого прогона `by_example` — числа до него
нет, и назначать его наугад значит мерить план по придуманной планке.

## Verify

`tests/unit/test_the_deck_is_measured_by_plan_b.py` — нарушитель мерила: слайд путём
дизайн-системы не считается «с примером». База 28.09 по фикстурам: по местам 24 из 24,
с примером 0, путём дизайн-системы 0.

## Что осталось незакрытым

Цель по «с примером» — после первого прогона `by_example`.
