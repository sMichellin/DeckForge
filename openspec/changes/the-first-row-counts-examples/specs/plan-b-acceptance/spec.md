# plan-b-acceptance

## MODIFIED Requirements

### Requirement: Строка 1 различает пример и его отсутствие
Строка 1 таблицы приёмки SHALL считать отдельно: слайды с примером по местам, а не
по смыслу; слайды с примером по смыслу; слайды без примера, собранные дизайн-системой.

#### Scenario: Слайд без примера
- **WHEN** у содержательного слайда нет примера, а причина — не «по местам»
- **THEN** он в счёте «путём дизайн-системы», а не «с примером по смыслу»

#### Scenario: Пример по местам
- **WHEN** причина выбора начинается словами «заказанного вида нет»
- **THEN** слайд в счёте «по местам, а не по смыслу»
