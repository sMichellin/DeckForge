# the-variants-are-named — варианты вёрстки называются словами

План Б, круг 3. Решение владельца 29.09: в интерфейсе вместо «A / B / C» — «Плотный аналитический»,
«Визуальный нарратив», «Executive summary». Файлы `frontend/**` и `src/deckforge/api/**` — зона
потока C; правку по поручению владельца делает тимлид, поток C предупреждён в #245.

## Explore

Переключатель «Вариант вёрстки» предлагал три буквы. Что за ними — плотность, порядок
слайдов, показ данных — знал только тот, кто читал `configs/variants.yaml`. Организатор,
который впервые открывает интерфейс, выбирает вслепую.

## Propose

* API: `GET /variants` → `{variant_id, name, rationale}` из `configs/variants.yaml`, как
  `GET /profiles` отдаёт профили с диска.
* Клиент: `variants()` → «буква → название»; отказ — пустой словарь.
* Интерфейс: переключатель показывает названия (`format_func`), значение — буква; без
  сервиса — буквы. Названий в коде нет: добавили вариант в конфиг — он появился в UI.

## Verify

`tests/unit/test_the_variants_are_named.py`: API отдаёт названия из конфига (норма),
клиент строит словарь (норма), мёртвый сервис — пустой словарь (нарушитель), страница без
сервиса предлагает буквы и не падает (нарушитель). Глазами — внешний UI стенда plan-b.

## Что осталось незакрытым

* На странице результата вариант не подписан вовсе — это отдельная правка, если понадобится.
