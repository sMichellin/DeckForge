# web-ui

## ADDED Requirements

### Requirement: Вариант вёрстки выбирается по названию
Интерфейс SHALL показывать варианты вёрстки их названиями из `configs/variants.yaml`
(«Плотный аналитический», «Визуальный нарратив», «Executive summary»), а в прогон SHALL
отправлять букву варианта. Названия интерфейс SHALL получать от сервиса (`GET /variants`)
и SHALL NOT знать их наперечёт. Если сервис недоступен, вариант SHALL выбираться буквой.

#### Scenario: Сервис назвал варианты
- **WHEN** `GET /variants` отдал буквы с названиями
- **THEN** переключатель «Вариант вёрстки» показывает названия, прогон получает букву

#### Scenario: Сервис недоступен
- **WHEN** `GET /variants` не ответил
- **THEN** переключатель показывает буквы A, B, C, страница не падает
