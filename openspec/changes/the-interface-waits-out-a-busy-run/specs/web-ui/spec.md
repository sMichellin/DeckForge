# web-ui

## MODIFIED Requirements

### Requirement: Интерфейс ждёт занятый сервис, но не ждёт мёртвый
Клиент интерфейса SHALL задавать таймауты раздельно: соединение — короткое, чтение —
долгое. Долгое чтение SHALL настраиваться переменной `DECKFORGE_UI_TIMEOUT_S`. Запросы
справочников, которые рисуют страницу (`/profiles`), SHALL уходить со своим коротким
таймаутом, чтобы недоступный сервис не задерживал разметку.

#### Scenario: Занятый сервис отвечает не сразу
- **WHEN** интерфейс запрашивает статус прогона
- **THEN** запрос уходит с таймаутом чтения больше прежних 30 секунд

#### Scenario: Адреса сервиса нет
- **WHEN** соединение с сервисом не устанавливается
- **THEN** клиент перестаёт ждать по короткому таймауту соединения

#### Scenario: Справочник профилей на каждой перерисовке
- **WHEN** интерфейс запрашивает список профилей
- **THEN** запрос уходит с коротким таймаутом справочника, а не с долгим таймаутом чтения
