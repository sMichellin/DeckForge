# pptx-writer

## ADDED Requirements

### Requirement: Зона слайда по рецепту получает кегль вписывания
Писатель слайда по рецепту SHALL ставить тексту зоны кегль, найденный вписыванием, когда
у блока с `zone_id` есть запись `SlideIR.fit_report[block_id]`: у каждого прогона текста
этой зоны `a:rPr/@sz` SHALL равняться `final_size_pt × 100`. Прогон без `a:rPr` SHALL
получать его; прочее оформление автора примера (гарнитура, цвет, начертание) НЕ SHALL
теряться. Записи нет — оформление зоны SHALL оставаться тем, что поставил автор примера.

#### Scenario: Запись о вписывании есть
- **WHEN** слайд по рецепту несёт блок в зоне, и `fit_report` этого блока даёт `final_size_pt` = 11
- **THEN** у каждого прогона текста зоны в записанном `.pptx` `a:rPr/@sz` = 1100
- **AND** полужирное начертание, цвет и гарнитура из `a:rPr` примера сохраняются
- **AND** прогон, у которого в примере `a:rPr` не было, получает `a:rPr` с `sz` = 1100

#### Scenario: Записи о вписывании нет
- **WHEN** у блока в зоне рецепта нет записи в `fit_report`
- **THEN** `a:rPr` каждого прогона зоны совпадает с `a:rPr` первого прогона фигуры примера
- **AND** если у примера `a:rPr` не было, его нет и у прогонов зоны
