# slide-composition

## ADDED Requirements

### Requirement: Закрывающий слайд не выдумывает сроков
Промпт композитора SHALL требовать, чтобы число в тексте закрывающего слайда бралось
только из фактов слайда. Нет числа в фактах — нет числа и в строке следующего шага.
Схема ответа при этом меняться SHALL NOT.

#### Scenario: Активный промпт несёт правило
- **WHEN** загружена активная версия промпта `slide_composer`
- **THEN** её системная часть запрещает выдумывать числа в строке следующего шага

#### Scenario: Контракт ответа не изменился
- **WHEN** сравниваются схемы ответа активной и предшествующей версий
- **THEN** они совпадают
