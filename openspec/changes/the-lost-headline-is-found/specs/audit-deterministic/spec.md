# audit-deterministic

## ADDED Requirements

### Requirement: Заголовок без слов не держит содержание слайда
Проверка `integrity.content_lost` SHALL давать находку на слайде, где нет ни одного
содержательного блока, а заголовок не содержит ни одного слова (две буквы подряд) —
число, знак, пусто, — даже если план не дал слайду фактов: заголовок плана — утверждение
словами, и слайд без него и без тела потерял содержание. Слайд с заголовком без слов,
на котором есть содержательный блок, SHALL NOT давать эту находку.

#### Scenario: Обложка с числом вместо заголовка
- **WHEN** на слайде только заголовок «1», фактов план не давал
- **THEN** находка `integrity.content_lost` с заголовком в `evidence`

#### Scenario: Обложка из заголовка словами
- **WHEN** на слайде только заголовок «Автоматизация создания презентаций»
- **THEN** находок нет

#### Scenario: Заголовок-число над телом
- **WHEN** заголовок «1», но на слайде есть текст тела
- **THEN** находки `integrity.content_lost` нет

#### Scenario: Строка 9 на прогонах 29.09
- **WHEN** переаудит фикстур `by_example` 29.09
- **THEN** `integrity.content_lost` и `integrity.empty_slide` — ровно WorkSpace s01, s10 и Education s10
