# web-ui

## ADDED Requirements

### Requirement: Три варианта из одной загрузки
Интерфейс SHALL предлагать в «Варианте вёрстки» пункт «все сразу». При нём шаблон
и материалы SHALL загружаться человеком один раз, а сервис SHALL получать по прогону на каждый
вариант с этими файлами. Результаты SHALL показываться вкладками, подписанными названиями
вариантов, у каждой — свои кнопки скачивания pptx, pdf и html.

#### Scenario: Все варианты
- **WHEN** выбран пункт «все сразу», загружены один шаблон и один текст, нажато «Собрать»
- **THEN** создано три прогона (A, B, C), в каждый загружены те же файлы, каждый запущен
- **AND** на странице три вкладки: «Плотный аналитический», «Визуальный нарратив», «Executive summary»

#### Scenario: Один вариант
- **WHEN** выбран один вариант
- **THEN** создан один прогон, страница такая же, как прежде
