# design-system-extraction

## ADDED Requirements

### Requirement: Ряд повторов виден и без компонента шаблона
Каталог композиций SHALL находить повторы по самому слайду-примеру, когда компонент
шаблона на нём не найден: одинаковые фигуры, стоящие сеткой с равным шагом, SHALL
считаться повторами. Повторами SHALL считаться вся сетка, а не первая её линия.
Ячейкой НЕ SHALL считаться фигура, в которую не влезает ни одного знака самым мелким
кеглем шаблона, а сетка, ни в одной ячейке которой нет текста автора, повторами
НЕ SHALL считаться.

#### Scenario: Ряд карточек, которого не увидел парсер
- **WHEN** на слайде-примере три одинаковые карточки с надписями, а компонента шаблона
  на этом примере нет
- **THEN** у рецепта три повтора
- **AND** адреса фигур каждого повтора попадают в `repeat_xml_ids`

#### Scenario: Сетка 3×2
- **WHEN** на слайде-примере шесть одинаковых карточек в две строки по три
- **THEN** у рецепта шесть повторов, а не три

#### Scenario: Точки-индикатор на обложке
- **WHEN** на слайде-примере пять одинаковых фигур, в которые не влезает ни одного знака
- **THEN** повторов у рецепта нет

#### Scenario: Сетка без текста автора
- **WHEN** на слайде-примере сетка одинаковых плашек и ни в одной нет надписи
- **THEN** повторов у рецепта нет

#### Scenario: Компонент шаблона найден
- **WHEN** компонент шаблона на этом примере есть
- **THEN** число повторов берётся из него
