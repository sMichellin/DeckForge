# the-writer-removes-whole-groups

План Б, change 4 (issue #244, поток B). Capability: `pptx-writer`. Статус: готово (28.09), живого прогона не было.
Ветка `feat/the-writer-removes-whole-groups` от `origin/plan-b` (`65d2a47`). Файлы:
`rendering/recipe_slide.py`, тест `tests/unit/test_the_writer_removes_whole_groups.py`
и его эталон `tests/fixtures/the-writer-removes-whole-groups/`.

## Зачем

Корень 3 плана Б: писатель, скопировав пример, **угадывает**, что на нём лишнее, — по номеру
повтора (`_drop_spare_repeats`), по зоне без текста (`_drop_empty_zones`) и по геометрии линий
(`_drop_orphan_decor`, допуск `TOUCH_SHARE`). Паспорт примера (ADR-009, change
`the-example-passport`) теперь знает это точно: какие места живут и уходят вместе (группа)
и какие группы взаимозаменяемы (ряд). Угадывание при паспорте больше не нужно.

Строка приёмки 3 — пустые карточки на слайдах по рецепту. VK Tech `ex018` (ряд `r1` из четырёх
карточек g02–g05 + широкая g06): legacy-IR 28.09 кладёт текст в g02 и g05, а g03, g04, g06 пусты —
плашки без текста на s02–s05, s07, s09. **До: 6 слайдов VK Tech.** Цель после — 0.

## Что меняется

С паспортом (`recipe.passport is not None`) `clone_recipe` идёт новым путём:

1. **Перенос в ряду** — до записи, как отображение «зона блока → зона цели». Группы ряда, в которые
   лёг наш текст, по порядку ряда переезжают в первые k групп, место в место (по номеру места
   в группе: форма у групп ряда одна). Блок IR не меняется — IR принадлежит композиции.
2. **Запись зон** — тем же `write_zone`, с кеглем вписывания блока.
3. **Удаление групп.** Группа заполнена, если хоть одно её текстовое место получило блок
   с непустым текстом. Незаполненная группа уходит целиком: фигуры мест и все `decor_xml_ids`;
   опустевший `p:grpSp` уходит следом (`_remove`). Группа с заголовком слайда не уходит никогда.
4. **Пустое место в заполненной группе** — его фигура удаляется; заголовок слайда остаётся
   и стирается (правило `_drop_empty_zones`).
5. **`_drop_unfilled_frames`** — вызывается и при паспорте (решение Насти 28.09: чужую
   незаполненную таблицу автора «Убирать»). Отступление от буквы issue («угадывающие функции
   не вызываются»): рамка таблицы/диаграммы в паспорт не попадает — паспорт строится по зонам
   и декору, а таблица автора на титуле WorkSpace `ex014` (`graphicFrame` 673, «Заголовок / Текст»)
   не зона и не декор. Без этой функции она уехала бы в колоду.

При паспорте **не вызываются** `_drop_spare_repeats`, `_drop_empty_zones`, `_drop_orphan_decor`.
Из кода они не удаляются вместе с `TOUCH_SHARE`: на них живёт `legacy`.

Без паспорта путь прежний — байт в байт; это сверяется с эталоном XML слайда, снятым **до**
правки кода (`tests/fixtures/the-writer-removes-whole-groups/`).

## Что выяснилось

- **Строка 3 «до/после».** Три колоды фикстур 28.09 (`from_fixture`) на шаблонах кейса;
  рецепты с паспортом — `with_passports(run.design_system, run.manifest, FontLibrary.default())`,
  «до» — тот же IR и те же рецепты с `passport=None`. Счёт скриптом в scratchpad (`measure/row3.py`,
  не в репозитории — решение §6): группа паспорта считается пустой, если её фигуры или декор
  на слайде есть, а текста ни в одном месте нет; группы заголовка не считаются.

  | Колода | До: слайдов с пустыми карточками | После |
  |---|---|---|
  | VK Tech | **6 из 10** (s02–s04, s09: g03, g04, g06; s05, s07: g03, g04 — все `ex018`) | **0 из 10** |
  | WorkSpace | 0 из 10 | 0 из 10 |
  | Education | 0 из 10 | 0 из 10 |

  Лист PNG глазами (`PptxWriter.write` → LibreOffice `soffice.com` → PDF → PyMuPDF): VK Tech «до» —
  на s02–s05, s07, s09 белые карточки с одной синей точкой без текста; «после» — только карточки
  с текстом, с начала ряда (по две на s02–s04, s09, по одной на s05, s07), пустых нет.
  Проверка потока C `integrity.empty_group` в `plan-b` ещё не влита — считал скрипт.
- **Иллюстрация уходит вместе с широкой карточкой.** Куб на VK Tech `ex018` — картинка группы g06;
  текста в g06 IR не кладёт, группа незаполнена и уходит с картинкой (s02–s04, s09). Это прямое
  следствие правила «незаполненная группа — целиком» и истории про место-картинку (ниже).
- **Аудит не изменился.** `reaudit` пересобранных колод с файлом колоды (скрипт `measure/audit_b.py`:
  `PptxWriter.write` → `reaudit` c `pptx_path`): находки по `check_id` «до» и «после» совпадают
  на всех трёх колодах (WorkSpace 1 ошибка / 4 предупреждения, VK Tech 0 / 5, Education 2 / 0);
  `template.sample_text_left` — 0 и 0. Пропущены только проверки, которым нужны судья или превью.
- **`plan_b_metrics.py` строки 4–6** по фикстурам (WorkSpace / VK Tech / Education) — совпадают с базой: снято блоков 2 / 4 / 5,
  сплющено 1 / 3 / 2, обрезано 0 / 2 / 3. Скрипт считает по `run.json`, писатель на эти
  строки не влияет — «не хуже» выполнено, но не доказывает ничего о change.
- **Холодный шаблон.** `tests/e2e/cold_corpus.py` ищет `.otp` по пути Linux-образа, на Windows
  корпус пуст и тест пропускается. Шаблоны LibreOffice из того же набора `_WANTED`
  (DNA, Focus, Piano, Portfolio) сконвертированы вручную
  (`soffice.com --headless --norestore --convert-to pptx`) в `tests/fixtures/templates/cold/`
  (в `.gitignore`): `tests/e2e/test_cold_template.py` — **4 passed**. Оговорка: этот тест собирает
  колоду по плейсхолдерам без рецептов, путь `clone_recipe` он не проходит; PDF-часть
  выполняется, только если `SofficeRenderer` видит офис.

## Что решено

- Перенос в ряду делается до записи отображением «зона блока → зона цели»; IR не меняется.
- Пустой блок (без строк) место не заполняет и не пишется.
- Место-картинка в заполненной группе остаётся (оформление автора), в незаполненной уходит
  с группой.
- Адрес декора может указывать на `p:grpSp` — узел ищется по всему дереву, не только среди фигур
  верхнего уровня.
- Эталон синтетики `legacy` переснят один раз прежним кодом, когда у широкой карточки появилась
  акцентная черта (коммит `371cbe3`, до первой правки кода); VK Tech `ex018` — снят до правки.
- Правило остановки не сработало: строка 3 сдвинулась (VK Tech 6 → 0), второй правки не было.
- По ревью: адрес текстового места — только адрес зоны (как при записи); дубль `cNvPr id`, который
  адресует паспорт (декор, место-картинка), — `RecipeError`, как дубль id зоны; без паспорта — как было.
  На трёх колодах 28.09 ошибок нет, строка 3 после правки та же (VK Tech 6 → 0).

## Что осталось незакрытым

- **Место-картинка.** Ассет в рецептный слайд писатель не ставит вовсе, поэтому группа, в которой
  только картинка, при паспорте считается незаполненной и уходит. Постановка ассета в место
  паспорта в issue не заказана — заявляется тимлиду. На VK Tech из-за этого вместе с пустой
  широкой карточкой уходит иллюстрация (куб) на 4 слайдах.
- **Холодный корпус на Windows.** `cold_corpus.py` знает только путь `/usr/lib/libreoffice/…`;
  локально шаблоны кладутся в `cold/` руками. Правка — в `tests/e2e/` (не зона потока B).
- **Живого прогона не было**: замер — на IR фикстур 28.09, а не на новой сборке стендом.
