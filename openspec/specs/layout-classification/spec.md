# layout-classification

## Purpose
Вид и вместимость макета без констант конкретных шаблонов: эвристика, VLM при низкой уверенности, кэш по геометрии.

## Requirements

### Requirement: Вид получает каждый макет
Классификатор SHALL проставлять `kind`, `kind_confidence` и `kind_source` каждому макету
манифеста. Технических значений вроде `pending` в готовом манифесте быть не SHALL.

#### Scenario: VLM-клиент не передан
- **WHEN** парсер создан без клиента модели
- **THEN** все макеты получают `kind_source = "heuristic"`
- **AND** разбор завершается успешно

#### Scenario: Инференс недоступен
- **WHEN** вызов модели поднимает исключение
- **THEN** сохраняется вид, полученный эвристикой

### Requirement: Модель зовут только на спорных макетах
Вызов VLM SHALL происходить только при `kind_confidence` ниже порога уверенности.

#### Scenario: Эвристика уверена
- **WHEN** уверенность эвристики не ниже порога
- **THEN** модель не вызывается ни разу

### Requirement: Голосование с эскалацией
При согласии первого вердикта модели с эвристикой дальнейшие прогоны SHALL не выполняться.
При разногласии SHALL выполняться голосование до заданного числа прогонов с разными seed.

#### Scenario: Ответ вне перечня видов
- **WHEN** модель вернула значение, которого нет в перечне `LayoutKind`
- **THEN** этот голос не засчитывается
- **AND** вердиктом не становится `custom`

### Requirement: Повторные вопросы не оплачиваются дважды
Макеты с одинаковой геометрией SHALL классифицироваться одним вызовом.
Отпечаток геометрии SHALL браться в долях слайда и не зависеть от его масштаба.

#### Scenario: Два макета с одинаковой геометрией и разными именами
- **WHEN** классифицируются два макета с одинаковой геометрией плейсхолдеров
- **THEN** модель опрашивается один раз — столько вызовов, сколько голосов у одного вопроса
- **AND** оба макета получают один и тот же вид

#### Scenario: Тот же макет в шаблоне другого масштаба
- **WHEN** геометрия плейсхолдеров пропорционально пересчитана под слайд другого размера
- **THEN** отпечаток геометрии совпадает с исходным
- **AND** сдвиг плейсхолдера внутри слайда отпечаток меняет

### Requirement: Превью не зависит от LibreOffice
Классификация SHALL работать на схематическом превью, не требуя внешнего конвертера.
Превью SHALL быть детерминированным: одинаковый макет даёт одинаковый PNG.

#### Scenario: Схематическое превью без внешнего конвертера
- **WHEN** макет отдаётся схематическому превью
- **THEN** возвращается PNG с пропорциями слайда
- **AND** LibreOffice для этого не нужен: проверка идёт в образе приложения, где его нет

#### Scenario: Два рендера одного макета
- **WHEN** один и тот же макет рендерится дважды
- **THEN** байты PNG совпадают
